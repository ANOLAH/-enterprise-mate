# Enterprise Mate

Marketing website for Enterprise Mate — Redefining Enterprise Resource Planning.

## Stack

- Vite + React + TypeScript
- Brand assets extracted from the company profile PDF

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://127.0.0.1:5173`).

## Build

```bash
npm run build
npm run preview
```
